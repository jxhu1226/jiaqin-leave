# 假勤

组织内部的请假审批小程序。成员提交请假，管理员同意或驳回，已通过的记录出现在全员都能看的公共日历上。后端用微信云开发（云函数 + 云数据库），不需要单独架服务器。

界面文字是简体中文。调试基础库请使用 **3.7.1** 或更高。

## 功能

- 用微信登录。身份以云函数上下文里的 openid 为准，客户端传过来的 openid 不会被当成当前用户。
- 资料里填写姓名和部门。没有姓名不能提交请假。
- 请假类型：事假、病假、年假、调休、其他。开始和结束可以精确到上午或下午，时长按半天自动计算。
- 成员查看自己的记录。状态为待审批、已通过、已驳回、已撤回。待审批的申请可以撤回。
- 与自己仍在待审批或已通过的时段重叠时，不能再提交。
- 管理员查看全部申请，可按状态、姓名、月份筛选，同意或驳回时可以留下意见。记录审批人和时间。
- 公共日历按月展示已通过的请假：谁、什么假、当天是全天还是上午/下午。点一天看明细。事由只对本人和管理员可见。
- 管理员可以把其他成员设为管理员，也可以取消。不能取消自己，组织里至少保留一名管理员。
- 「审批」标签只对管理员显示，上面有待审批数量。

## 目录

```
project.config.json          微信开发者工具项目配置（appid 目前是占位）
miniprogram/                 小程序前端
  config.js                  云环境 ID
  pages/calendar             公共日历
  pages/leave                我的请假
  pages/leave-form           提交申请
  pages/leave-detail         详情、撤回、审批
  pages/approval             管理员审批
  pages/profile              资料、OpenID、首位管理员
  pages/members              成员与角色
cloudfunctions/auth          登录、资料、角色
cloudfunctions/leave         请假、审批、日历
cloud-shared/config.js       首位管理员配置的源文件
shared/                      时长、日历、权限的纯逻辑源文件
scripts/sync-shared.js       把 shared 和 cloud-shared 同步到小程序与云函数
test/                        node:test 单元测试
```

小程序和云函数使用的是同步后的副本。改 `shared/` 或 `cloud-shared/config.js` 之后要执行 `npm run sync-shared`，否则测试不会通过，上传的云函数也不会带上新逻辑。

## 本地测试

不需要微信开发者工具，也不需要云环境。

```bash
npm test
```

需要 Node.js 18 或更高。测试覆盖请假时长、半天重叠、日历分组、表单校验，以及同意、驳回、撤回、设管理员这些权限判断。

## 导入微信开发者工具

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 稳定版。
2. 选择「导入项目」，目录选这个仓库的根目录（能看到 `project.config.json` 的那一层）。
3. 后端服务选择「微信云开发」。

`project.config.json` 里的 AppID 目前是 `touristappid`，只为了让项目能先打开。云开发必须使用你自己的小程序 AppID。在开发者工具的项目详情里改成真实 AppID，或直接改 `project.config.json` 的 `appid` 字段。

把调试基础库设为 3.7.1 或更高。

## 开通云开发并填写环境 ID

1. 在开发者工具顶部打开「云开发」，按提示开通，创建一个环境。
2. 在云开发控制台的「设置」里复制环境 ID，形如 `cloud1-xxxxxxxx`。填写环境 ID，不是环境名称。
3. 把 ID 写入 `miniprogram/config.js` 的 `envId`。
4. 重新编译。

未填写环境 ID 时，页面会提示云开发尚未就绪，不会去调用云函数。

## 部署云函数

云函数目录里只有两个函数：

- `auth`：登录、修改资料、成员列表、设置角色、使用初始化口令
- `leave`：提交、撤回、我的记录、全部记录、审批、详情、日历

在开发者工具的云函数面板中，对 `auth` 和 `leave` 分别右键，选择 **上传并部署：云端安装依赖**。不要只上传不装依赖，`wx-server-sdk` 需要在云端安装。

首次登录会尝试创建 `users` 和 `leaves` 两个集合。如果创建失败，就在云开发控制台的数据库里手动新建这两个集合。

## 数据库权限

这一步需要手动完成，云函数无法替你改权限。

把 `users` 和 `leaves` 都设为 **所有用户不可读写**（仅管理端可读写）。云函数使用管理员权限，不受这条规则限制。

如果保持默认的「仅创建者可读写」或「所有用户可读」，客户端就可以绕过云函数，直接写入一条已通过的请假。审批和日历就不再可信。

集合可以不建索引。列表在云函数里取出后再筛选、排序。数据量很大时，再按 `status`、`openid`、`endDate` 补索引。单次查询最多处理约 1000 条，管理列表和我的记录最多返回最近 200 条。

## 设置首位管理员

小程序发布范围请限定在组织内（体验成员，或企业内部可见）。能打开小程序的人都会成为成员，本程序不再做一道注册审批。

任选一种方式设置第一位管理员。

### 方式 A：指定 openid

1. 用自己的微信号编译并打开小程序，进入「我的」，复制 OpenID。
2. 把 OpenID 填进 `cloud-shared/config.js` 的 `BOOTSTRAP_ADMIN_OPENIDS`。可以填多个。
3. 在仓库根目录执行 `npm run sync-shared`。
4. 重新上传并部署 `auth` 云函数。
5. 回到小程序的「我的」页下拉刷新。名单里的 openid 会在登录时被设为管理员，「审批」标签随之出现。

从名单里删掉某个人，不会自动取消他的管理员身份。取消请到「成员管理」。

### 方式 B：初始化口令

1. 在 `cloud-shared/config.js` 里设置 `INIT_ADMIN_CODE`，例如一串只有你知道的口令。留空表示关闭。
2. 执行 `npm run sync-shared`，重新上传 `auth`。
3. 打开小程序，在「我的」底部输入口令。此时还没有任何管理员的话，你会成为管理员。
4. 成功后把口令改回空字符串，再次同步并上传 `auth`，避免口令继续有效。

已经有管理员之后，口令不能再把别人提升为管理员。之后请用「成员管理」授权。

如果仓库会分享给其他人，不要把正在使用的口令留在代码里。

## 使用说明

成员在「请假」里提交申请，在详情页撤回待审批的记录。管理员在「审批」里处理，也可以从日历点进自己或任意一条已通过记录的详情再审批。

日历只展示已通过的请假。待审批、已驳回、已撤回都不会出现。请假单上的姓名是提交当时的姓名，之后改资料不会回写旧记录。今年已通过的天数按开始日期所在年份累计。

管理员可以审批自己的申请，记录里会写上审批人。

## 数据

`users` 的文档 ID 就是 openid。

| 字段 | 说明 |
| --- | --- |
| openid, name, department | 身份与资料 |
| role | `member` 或 `admin` |
| createdAt, updatedAt | 毫秒时间戳 |

`leaves`：

| 字段 | 说明 |
| --- | --- |
| openid, userName, department | 提交人快照 |
| type | 事假 / 病假 / 年假 / 调休 / 其他 |
| startDate, endDate | `YYYY-MM-DD` |
| startHalf, endHalf | `am` 上午，`pm` 下午 |
| duration | 天数，最小 0.5 |
| reason | 事由 |
| status | `pending` / `approved` / `rejected` / `withdrawn` |
| reviewComment, reviewerOpenid, reviewerName, reviewedAt | 审批信息 |
| createdAt, updatedAt | 毫秒时间戳 |

时间在界面上按北京时间显示。日期只存日历日，避免时区把跨天算错。

## 权限（云函数强制）

| 操作 | 成员 | 管理员 |
| --- | --- | --- |
| 提交、查看、撤回自己的待审批申请 | 可以 | 可以 |
| 查看全部申请，同意或驳回 | 不可以 | 可以 |
| 查看公共日历（不含事由） | 可以 | 可以 |
| 查看事由和审批意见 | 仅自己的 | 全部 |
| 修改他人角色 | 不可以 | 可以 |

直接调用 `leave` 的 `list` 或 `review`，非管理员会收到「仅管理员可以执行此操作」。

## 常见问题

**编译后提示云开发尚未就绪。**  
检查 `miniprogram/config.js` 的 `envId`，确认 `auth`、`leave` 都已「云端安装依赖」并上传成功，且当前 AppID 已经开通这个云环境。

**登录成功但没有审批入口。**  
首位管理员还没配好。按上面的方式 A 或 B 做完后，在「我的」下拉刷新。

**同意之后日历没有这条记录。**  
日历只看已通过，并且要包含这一天。换到对应月份，或下拉刷新。

**数据库报缺索引。**  
当前查询在失败时会退回全表扫描。如果日志里仍提示创建索引，点开日志里的链接建索引即可，功能不依赖预先建好的索引。

**游客模式不能用云函数。**  
把 AppID 换成自己的小程序，再开通云开发。
